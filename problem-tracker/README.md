# 项目问题迭代记录

这里记录项目评审发现的问题、源码依据、解决方案和验证结果。

## 记录规则

- 每一轮评估只使用一组文件：`problemN.md` 与 `solutionN.md`。
- `problemN.md` 中使用“问题1、问题2、问题3”记录该轮全部问题。
- `solutionN.md` 中使用“问题1的解决方案、问题2的解决方案、问题3的解决方案”逐项对应。
- 只把已经核对源码的问题登记为“确认”或“部分成立”。
- 问题修复后保留原文件，在 `solutionN.md` 中补充实施记录，不覆盖历史判断。

## 当前优先级

1. 上下文预算与记忆压缩输入边界。
2. 会话并发控制。
3. AIOps 结构化证据与普通聊天工具输出分离。
4. 评测失败处理、数据集和相关性标注。
5. SOP belief 的租户隔离、归因准确性和反馈幂等。

当前 `problem1.md` 与 `solution1.md` 记录第一轮评估发现的 13 个问题及其解决方案。下一轮评估使用 `problem2.md` 与 `solution2.md`。
